# 少刷

少刷是 Windows 上的 Edge / Chrome 扩展，用于抖音和 B 站网页版。它根据当前标签页的观看时间逐步减少续刷入口，再给你一个明确的停靠点。

## 安装

1. 在仓库首页点击「Code → Download ZIP」，下载并解压。
2. 用 Edge 打开 `edge://extensions`，或用 Chrome 打开 `chrome://extensions`。
3. 打开「开发人员模式」，点击「加载解压缩的扩展」。
4. 选择解压目录里的 `extension` 文件夹，也就是直接包含 `manifest.json` 的那一层。
5. 刷新已经打开的抖音或 B 站网页。点击浏览器工具栏里的「少刷」调整时长。

## 默认如何工作

| 观看时间 | 扩展行为 |
| --- | --- |
| 约 2 分钟 | 收起 B 站视频页可识别的相关推荐。 |
| 约 5 分钟 | 收起 B 站可识别的首页推荐区和播放结束推荐面板。抖音会收起可识别的下一条按钮，并限制播放器区域内向下滚轮和下方向键切换。 |
| 约 10 分钟 | 暂停网页里的视频。「离开视频」会跳转到空白页。「再看 2 分钟」会关闭提醒，之后需要手动恢复播放。 |

只累计可见标签页中、位于视口内且正在播放的视频时间。标签页切换、视频暂停和缓冲期间不计时。同一标签页内刷新或在同站继续浏览，通常可沿用计时。没有观看约 20 分钟后会开启新一轮。可在设置里选 1 分钟试跑，前两步会分别提前到约 12 秒和 30 秒。

扩展作用于 `www.douyin.com` 和 `www.bilibili.com` 的桌面网页。它改变浏览器呈现和交互，平台仍按自己的推荐机制提供内容。网站更新布局后，可能需要调整用于识别推荐入口的选择器。安卓原生 App 暂无安装包，网页版也还没有做安卓适配。

## 数据

设置保存在浏览器的扩展本地存储。当前标签页的累计时长和续看期限保存在该站点的标签页会话存储中，站点页面脚本可以读取这几项数值。扩展没有网络请求，不记录视频链接、标题或账号信息。
